# DBMS ETL & Data Mart Project

## Overview

This project was completed as part of the Database Management course at Sheridan College. The objective was to design and implement an ETL (Extract, Transform, Load) process and develop a Data Mart to support reporting and analytical requirements.

The project involved extracting data from multiple sources, transforming and validating the data, and loading it into a structured Data Mart using data warehousing concepts and best practices.
